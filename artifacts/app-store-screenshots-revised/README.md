## サンプルデータ

- 予定：小旅行、出張、週次ミーティング、食材の買い出し、企画書の確認、クリーニング受け取り。
- 支出カテゴリ：食費、日用品、住居、光熱費、通信費、サブスク、医療、娯楽。
- 主な項目：家賃 88,000円、電気・ガス 12,500円、スマホ代 6,800円、動画配信 1,490円、食費、日用品、通院、映画・レジャー。給与は月310,000円。
- 定額項目は2026年1月からの繰り返し、食費・日用品・医療・娯楽は月により金額を変えて年間推移に反映しています。10月分は一部を実績登録しています。

## 現行UI上の表示について

- 通知選択シートでは「大切」の通知3つを現行UIが「3件」と要約します。選択済み状態は10分前・30分前・1日前のチェックで分かります。「ほどほど」は「10分前」と表示されます。
- お金登録は予定登録とは別の機能です。05は登録、06は月の見込みと実績、07は年間分析の画面です。
