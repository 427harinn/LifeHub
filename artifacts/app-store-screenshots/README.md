# App Store提出用スクリーンショット素材

LifeHubの現行UIを390×844 pxで撮影したPNGです。2026年10月2日（Asia/Tokyo）の日付で、日本語のサンプルデータを登録しています。広告用の背景・見出し・後加工は加えていません。

| ファイル | シナリオ | 画面で見せる内容 |
| --- | --- | --- |
| `01_month_calendar.png` | 月カレンダー | 2026年10月の月表示、「すべて / 家 / 仕事 / お金」の切り替え、複数の予定と日別の収支。日付シートは閉じた状態。 |
| `02_daily_view.png` | デイリー表示 | 10月2日の予定を時刻順に表示。家・仕事の予定、期間予定、今日のお金を確認できます。 |
| `03_flexible_date_setting.png` | 柔軟な日付指定 | 「クリーニング受け取り」の追加画面。「期間中にやりたい」を選択し、種類選択シートで「日時が決まっている」も確認できます。 |
| `04_notification_categories.png` | 通知設定 | 通知テンプレート「大切」「ほどほど」を管理する画面。複数通知と再利用カテゴリを示します。 |
| `05_planned_expenses.png` | 支出予定の登録 | 動画配信を「予定」として登録する画面。金額と毎月の繰り返しを設定しています。 |
| `06_monthly_money_summary.png` | 月のお金管理 | 10月の支出見込み・収入見込み・残りそうな金額と、予定・実績の項目一覧。 |
| `07_yearly_money_review.png` | 年単位の振り返り | 2026年の見込み集計、カテゴリ別支出、1月から12月までの月別推移。 |

## サンプルデータ

- 予定：歯科検診、週次ミーティング、食材の買い出し、企画書の確認、実家に連絡、クリーニング受け取り。
- 毎月の支出予定：家賃 88,000円、電気・ガス 12,500円、スマホ代 6,800円、動画配信 1,490円、食費 52,000円。
- そのほか：日用品 3,600円、給与 310,000円。10月分は一部を実績にしています。
- 年間推移を表示するため、繰り返し項目は2026年1月開始で登録しています。

## 補足・現行UI上の制約

- 予定とお金は別々の記録です。05は支出予定の登録、06・07は登録後の集計を見せる構成です。
- 「大切」は10分前・30分前・1日前、「ほどほど」は10分前の通知です。現行のテンプレート一覧は3つ以上の通知を「3件」と要約するため、04の画面上では「大切」の個々の時刻までは展開されません。時刻の詳細確認は、テンプレート編集画面で行う実装です。
- 日別のお金の詳細を独立した一覧で見せる画面は現行UIにありません。01で日別収支、06で月の合計と項目一覧を確認できます。
- 画面にない機能や宣伝用デザインは追加していません。
