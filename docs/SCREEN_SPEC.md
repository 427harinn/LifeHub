# LifeHub 画面仕様

## 1. 共通方針

- スマートフォンファースト
- HouseToDoのUIデザイン・余白・BottomSheet・フォーム行・Bottom Navigationを強く参考にする
- タップ数と選択回数を減らす
- 高度な設定は必要なときだけ表示する
- 月表示 → 日付詳細 → デイリー → 予定詳細の順で情報量を増やす
- 予定アプリとして扱い、完了ボタン・チェックボックス・未完了状態は表示しない
- Calendarをアプリの中心画面とし、一般的なコンパクト月表示より大きく、多くの予定情報を見せる

---

## 2. カレンダー

アプリのメイン画面。
390×844を基準に、月表示そのものへ十分な高さを割り当てる。

### タブ

- すべて
- 家
- 仕事
- お金

### 日セルの情報順

日セル内は上から以下の順を基本とする。

1. 日付
2. その日の金額表示
3. 予定
4. 表示しきれない場合の `+N`

Calendarは情報量を優先する。
1日あたりの予定最大表示件数は仕様段階で固定せず、実装時に390×844へ最大量のダミーデータを入れて、可読性を保てる件数を確認した後に決定する。

### すべて

日セルには以下を表示する。

- その日の金額合計
- 家の予定
- 仕事の予定

お金の個別明細はここでは出さない。
金額は予定一覧より上に置く。

### 家

家カテゴリの予定のみ表示する。

### 仕事

仕事カテゴリの予定のみ表示する。

### お金

その日のMoney occurrenceを表示する。
通常予定の帯よりも金額情報を優先する。

例:

- -1,500
- -5,000
- +2,999

表示しきれない場合は `+N件` などで省略できる。

### 予定の色分け

予定カテゴリの家 / 仕事ではなく、予定の性質で基本色を分ける。

1. 今回だけの通常予定
2. 繰り返し予定
3. 期間内の予定（今週中 / 今月中 / 任意期間）

この3種類がCalendar上で見分けられる色を持つ。
LifeHub全体のオレンジ系デザインシステムと調和させ、派手すぎる原色は避ける。

家 / 仕事の区別は、必要に応じて小さなラベル・アイコン・補助トーンで表現し、予定種別の色分けと競合させない。

### 複数日予定

複数日にまたがる通常予定は、TimeTreeのように同一予定を横方向へつないだ帯として表示する。

- 予定名を毎日セルごとに繰り返さない
- 同一週内ではできる限り1本の連続した帯にする
- 週境界では次の週行へ継続する
- 帯の開始・途中・終了が視覚的につながって見えるようにする
- 日セルごとの独立カードにはしない

### 今週中 / 今月中 / 期間予定

期間中にやりたい予定も対象期間をまたぐ帯として表示する。
通常の複数日予定と同様に連続帯として扱うが、**期間予定専用色**を使って通常予定・繰り返し予定と区別する。

`今週中` はその週の対象範囲、`今月中` は対象月の範囲を横断する。
月表示の週境界をまたぐ場合は週行ごとに帯を分割して描画してよいが、同一Eventであることが分かる見た目にする。

期間予定に完了チェックは表示しない。
対象期間を過ぎたら過去の予定としてその位置にそのまま残る。

### 予定が多い日

表示上限を超えた予定は無理に詰め込まず、最後に残件数を表示する。

例:

```text
+1
```

```text
+3
```

タップするとその日の日付詳細で全件確認できる。

### 日付タップ

日付を押すとBottomSheet形式の簡易日付詳細を開く。

表示内容:

- 日付
- 時系列の予定一覧
- その日を含む期間予定
- その日の金額合計
- 「1日の詳細を見る」導線
- その日を初期値にした追加導線

予定メモ全文などはここでは表示しない。

### 検索

Calendar内に検索導線を置く。

検索結果は一覧表示し、選択すると:

1. 該当月へ移動
2. 該当日を選択
3. 日付詳細を開く

検索対象:

- タイトル
- 場所
- メモ

ローカルアーカイブ済みデータも検索対象に含められる設計にする。

## 3. デイリー

1日単位の詳細を見る画面。
HouseToDo Homeの縦スクロール構造を参考にする。

### 日付操作

- 前日
- 翌日
- 今日へ戻る

Calendarから選択した日付を引き継ぐ。

### タブ

- すべて
- 家
- 仕事
- お金

### すべて

上から以下の順に表示する。

1. 予定タイムライン
2. 今日のお金
3. 今日のメモ

#### 予定タイムライン

縦方向のタイムライン表示を基本とする。

タイムライン内の順序:

1. 終日予定
2. 今週中 / 今月中 / 任意期間の期間予定
3. 時間あり予定を時刻順

終日予定と期間予定はタイムライン上部へ積み、固定時刻を持つ予定はその下を時刻順に表示する。

時間あり予定と終日予定は同じ「予定タイムライン」というまとまりに含める。
期間予定も上部セクションとして同じ予定領域に含める。

### 家 / 仕事

該当カテゴリの予定だけを同じタイムライン構造で表示する。

### お金

タイムラインの下に今日のお金を表示する。
`すべて` タブでは簡潔な合計・主要明細を表示し、`お金` タブでは個別収支を詳しく表示する。

例:

- 食費 -1,500円
- 電気代 -5,000円
- 副収入 +2,999円

予定額・実績額の詳細確認もこの画面または詳細画面から行えるようにする。

### 今日のメモ

お金の下に配置する。
1日単位の軽いメモ。
「日記」という名称は使わず、書かなくても違和感がないUIにする。

## 4. ＋追加

中央の＋を押すと最初に小さな選択UIを出す。

- 家
- 仕事
- お金

これ以外の中間選択画面は原則増やさない。

---

## 5. 家・仕事の登録画面

詳細は `EVENT_FORM_SPEC.md` を正とする。

通常予定は詳細画面から編集・削除できる。
繰り返し予定は `今回のみ / これ以降 / すべて` を選択して編集・削除する。

---

## 6. お金登録画面

詳細は `MONEY_SPEC.md` を正とする。

基本項目:

1. 支出 / 収入
2. タイトル
3. 金額
4. カテゴリ
5. 日付
6. 必要なら時間追加
7. 繰り返し
8. メモ
9. 登録

通知は持たない。

---

## 7. お金画面

上部タブ:

- 今月
- 月ごと

### 今月

上部に大きく:

- 支出見込み
- 収入見込み
- 残りそう

その下に:

- 実績 / 見込みの簡潔な内訳
- カテゴリ構成グラフ
- カテゴリ別金額
- 今月のお金一覧

### 月ごと

- 月別推移グラフ
- 月単位の支出 / 収入

月を選択すると詳細へ進める。

過去月は実績 + みなし実績で集計する。
今月は予定額を含む着地見込みとして扱う。

---

## 8. 設定

HouseToDoの設定/その他画面構造をベースにする。

初期項目:

- アカウント
- 通知
  - 朝のまとめ通知 ON/OFF
  - 朝のまとめ通知時刻（初期09:00）
  - 夜のまとめ通知 ON/OFF
  - 夜のまとめ通知時刻（初期21:00）
  - 通知テンプレート
- カレンダー
  - 週の開始曜日
- お金
  - お金カテゴリ
- データ
  - 機種変更 / バックアップ
  - バックアップを書き出す
  - バックアップを読み込む
  - ローカルアーカイブ状態
  - 必要に応じて手動アーカイブ
- その他アプリ設定

共有設定は持たない。

---

## 9. データアーカイブ表示

古いデータがD1から端末IndexedDBへ移動済みでも、通常のCalendar / Daily / Money画面から可能な限り同じように閲覧できるようにする。

ユーザーに「これはDB」「これはローカル」と毎回意識させない。

ただし設定画面では以下を確認できるようにする。

- クラウド保持期間（初期1年）
- ローカルアーカイブ件数 / 対象期間
- 最終エクスポート日時
- 機種変更状態

端末データを消すとローカルアーカイブも失われる可能性があるため、バックアップ未作成時にはその旨を分かりやすく表示する。

---

## 10. 画面間の戻り動作

HouseToDoで実装した `returnTo` の考え方を継承候補とする。

例:

- Calendarの9/10から追加 → 登録後9/10のCalendarへ戻る
- Dailyの過去日から追加 → 登録後同じ日のDailyへ戻る

戻る操作でも元の画面・選択日をできる限り維持する。
